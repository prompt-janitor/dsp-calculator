# Dyson Sphere Calculator

A production planner for [Dyson Sphere Program](https://store.steampowered.com/app/1366540/). Pick what you want to make and how fast, and it shows:

- every production step
- how many of each building to place
- belt lines and power
- a flow map you can pan and zoom

It works on phones, tablets and desktop, and keeps working offline once installed.

Live site: <https://prompt-janitor.github.io/dsp-calculator/>

## Install on iPhone or iPad

Open the site in Safari, tap Share, then choose **Add to Home Screen**.

## Development

```sh
npm test
npm run serve   # http://localhost:8080
```

Pushing to `main` deploys the site to GitHub Pages.
